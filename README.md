# Сайт автостанции Беседина

Обновлено 21.10.2026. **Сайт опубликован:** https://a6340374-stack.github.io/  
**Исходники на GitHub:** https://github.com/a6340374-stack/a6340374-stack.github.io

**Назначение:** русскоязычный сайт для поиска рейса и звонка диспетчеру. Он опубликован как информационная первая версия; фактические реквизиты оператора сайта и место посадки ещё уточняются.

**Принимает:** запрос страницы и контент из подтверждённого источника владельца.

**Отдаёт:** сведения о маршрутах и контакты, переход к звонку. На этапе 1 не оформляет билет и не показывает свободные места.

**Зависимости:** GitHub Pages уже подключён; для дальнейшего наполнения нужны проверенные бизнес-данные. Аккаунты поисковых систем пока не подключены.

**Стек:** Astro 7.4.1, статическая сборка, локально размещённые шрифты Manrope и Playfair Display.

**Локальные команды:** `npm run dev`, `npm run build`, `npm run preview` из этой папки.

**Контент:** `src/data/routes.ts` — направления, времена, тарифы и номер диспетчера. `src/scripts/search.ts` — фильтрация, дата и мобильное меню. Форма не отправляет заявки. Источники и подтверждения описаны в `../docs/CONTENT-SOURCES.md`.

**Если компонент недоступен:** пассажир может связаться с диспетчером по подтверждённому номеру +7 (917) 432-49-70.

## Страницы и метаданные

- `/` — поиск и расписание всех направлений.
- `/marshruty/sibay-magnitogorsk/`, `/marshruty/sibay-orenburg/` — статические страницы из общего массива маршрутов.
- `/kontakty/` — телефон и адрес со ссылкой на реестр Минтранса.
- `/404.html` — страница ошибки с noindex; статус ответа настраивается на хостинге.

`src/components/PageMeta.astro` содержит общие метаданные. Canonical для страниц строится по адресу GitHub Pages, указанному в `astro.config.mjs`. Подробности этапа — `../docs/PASSENGER-PAGES.md`.

## GitHub Pages

Адрес `https://a6340374-stack.github.io/` указан в `astro.config.mjs`. Workflow `.github/workflows/deploy.yml` собирает сайт из корня этого репозитория и отправляет результат на GitHub Pages. Для публикации используется репозиторий `a6340374-stack/a6340374-stack.github.io`; отдельный `base` не требуется. `public/robots.txt` и `public/sitemap.xml` перечисляют подтверждённые страницы. При смене домена обновить все три места.

Первый опубликованный коммит: `0a561b6b09eef34774d7831a2e2f1bb4bb05716a`, [успешный запуск Actions](https://github.com/a6340374-stack/a6340374-stack.github.io/actions/runs/39516868717). После публикации главная, две страницы направлений, контакты и sitemap отвечали HTTP 200. Ветка публикации — `main`. Для отката восстановить последний рабочий исходный код новым коммитом и дождаться нового успешного запуска.

## Подтверждённые данные и решения

- Пользователь подтвердил номер диспетчера, цены из Сибая: 400 ₽ до Магнитогорска и 1 400 ₽ до Оренбурга, отправление до Оренбурга 23:55 и обратный рейс Магнитогорск → Сибай в 16:00. Остальное расписание перенесено из двух предоставленных фотографий; неизвестные сведения отмечены как требующие звонка.
- Форма поиска фильтрует известное расписание по городам и дате. Она не отправляет заявку, не создаёт бронь и не сообщает остатки мест. Диспетчер подтверждает поездку.
- На мобильной главной сохранён прежний зелёный первый экран с фотографией автобуса. Пользователю этот вариант понравился больше; после временной перестановки поиска прежний вид восстановлен.
- Адрес АС г. Сибай по [реестру Минтранса](https://mintrans.gov.ru/opendata/7705851331-stoppointsmzd/view): ул. Лермонтова, 39/1, владельцем остановочного пункта указан ИП Беседин Валерий Васильевич. Точный вход и место посадки отдельного рейса необходимо уточнить у диспетчера.
- Билетная платформа с общим учётом мест и продажами, а затем ИИ-диспетчер — будущие отдельные компоненты, которые планируется связать через API.

## Открытые вопросы

1. Уточнить часы ответа диспетчера, график кассы, точный вход и место посадки. Открытые источники расходятся по часам работы; сайт пока не публикует точный график.
2. Назначить ответственного за актуальность расписания, тарифов и срочные изменения.
3. Установить действующие реквизиты продавца и оператора сайта; подготовить политику обработки персональных данных для фактического хостинга.
4. Подтвердить право использовать предоставленные фотографии, особенно снимки салона с отметками сторонних сайтов, или заменить их собственными.
5. Выбрать собственный домен при необходимости и подключить Яндекс Вебмастер и Google Search Console. Текущий адрес доступен публично, но это не подтверждает индексацию.
